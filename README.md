# Weather Fetcher App

This Python script allows you to fetch current weather data for any city (e.g., Pokhara, Baglung, Kathmandu) using the OpenWeatherMap API and display it in a nicely formatted table.

---

## Features

✅ Get weather by entering city name interactively  
✅ Fetch temperature, humidity, pressure, wind speed, and weather description  
✅ Display data in a clean pandas DataFrame  
✅ Easy to extend (e.g., save to CSV, loop over multiple cities)

---

## Requirements

- Python 3.x  
- `requests` library  
- `pandas` library  
- OpenWeatherMap API key (free signup at https://openweathermap.org/api)
